# Jadwal Foto TKA Kelas XII 2026 — SMKN 3 Linggabuana

Halaman ini untuk GitHub Pages. Domain-nya nanti:

`https://USERNAME.github.io/NAMA-REPO/`

## Isi repo

```
nama-repo/
├── index.html
├── README.md
└── fotos/
    ├── 0081935299.jpg
    ├── 0098475532.jpg
    └── ... (nama file = NISN)
```

## 1. Buat repo di GitHub

1. Login GitHub → **New repository**
2. Nama bebas, contoh: `foto-tka-xii-2026`
3. Public
4. Create repository

## 2. Upload file

Upload `index.html` ke root repo.

Buat folder `fotos`, lalu upload foto. Nama file harus persis NISN:

- Benar: `0081935299.jpg`
- Salah: `0081935299 .jpg` / `0081935299.JPG` / `david.jpg`

Kalau 321 file terlalu banyak sekaligus, upload per jurusan.

## 3. Nyalakan GitHub Pages

Repo → **Settings** → **Pages**

- Source: **Deploy from a branch**
- Branch: `main` (atau `master`)
- Folder: `/ (root)`
- Save

Tunggu 1–2 menit. Web hidup di:

`https://USERNAME.github.io/foto-tka-xii-2026/`

## 4. Foto jangan ukuran asli

GitHub juga akan berat kalau foto masih 3–8 MB per file.

Kompres dulu sebelum upload:

- Lebar sekitar 400–600 pixel
- Target ±40–80 KB per foto
- 321 siswa × 60 KB ≈ 20 MB → aman untuk GitHub Pages

Alat kompres: ILoveIMG, Squoosh, atau Photos di HP (export kualitas sedang).

## 5. Cek foto

Setelah 1 file ter-upload, buka:

`https://USERNAME.github.io/foto-tka-xii-2026/fotos/0081935299.jpg`

Kalau foto muncul, refresh halaman utama. Yang belum ada filenya tampil inisial nama, tidak error.
